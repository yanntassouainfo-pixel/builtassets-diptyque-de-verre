# Built Assets · « Diptyque de verre »

Proposition de refonte du site de Built Assets (construction, AMO, immobilier et solutions énergétiques, Lomé). Direction artistique, maquettes et site navigable : Yann Tassoua, octobre 2026.

**Voir le site de démonstration :** https://yanntassouainfo-pixel.github.io/builtassets-diptyque-de-verre/

> Ceci est une maquette, pas le site officiel de Built Assets. Le site officiel est [builtassets.com](https://builtassets.com/fr/). Les pages de démonstration ne sont pas indexées par les moteurs de recherche.

## Le principe

Le papier pour lire, le verre pour la photo.

- **Diptyque** apporte les doubles pages photo et texte, les folios numérotés, la palette ivoire, sauge et olive, et les titres en serif fine.
- **Verrière** apporte les panneaux de verre dépoli posés sur la photographie, les chiffres sur verre et l'en-tête translucide.
- **La signature, le « pont de verre » :** à la couture de chaque double page, un panneau de verre chevauche la photo et porte le message clé.
